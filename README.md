# AI Creative Director — 完全版フロントエンド

AI Creative Director 01〜10 実装指示書と、01〜10の完成画面を基準にしたブラウザ実装です。

## 起動

`index.html` をブラウザで開いてください。外部ビルドツール不要です。

## 実装範囲

- 01〜10の10画面
- 01→10の工程遷移
- 会社情報・企画・編集状態の保持（localStorage）
- 企業情報入力・文字数カウンター
- AI分析中UI
- ブランド分析・広告戦略・クリエイティブ企画
- 素材追加UI
- 動画生成UI・再生UIとAIチャット送信の分離
- AI修正案→確認→適用
- バージョン履歴
- 最終チェック
- 出力先・出力設定・公開オプション・下書き保存・書き出し開始UI

## 注意

AI分析、動画生成、クラウド保存、SNS公開、実ファイルエンコード等のサーバー側処理はモックUIです。実サービス化する場合はAPI/バックエンドを接続してください。
